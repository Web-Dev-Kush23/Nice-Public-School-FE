# Nice Public School Website

A modern and responsive school website built using **HTML**, **CSS**, and **JavaScript**.  
This project is designed for educational institutions to showcase their school information, courses, facilities, events, and contact details in a professional and attractive way.

---

## 📌 Features

- ✅ Fully Responsive Design
- ✅ Modern Hero Section
- ✅ About School Section
- ✅ Courses / Academics Section
- ✅ Facilities Showcase
- ✅ Gallery Section
- ✅ Teacher / Staff Section
- ✅ Student Testimonials
- ✅ Contact Form
- ✅ Smooth Scrolling Navigation
- ✅ Interactive UI using JavaScript
- ✅ Clean and Organized Code Structure

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
